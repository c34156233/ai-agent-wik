# Microsoft Copilot Studio - Agents Overview

來源：
https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-overview

## 摘要

Agent 是能理解企業情境並代替使用者執行工作流程的 AI 系統。

## Agent 能力

### Reasoning

處理複雜的多步驟任務。

### Automation

自動執行工作流程。

### Action

透過工具與 API 執行實際操作。

### Memory

保留對話上下文。

## Agent 可做的事情

- 建立文件
- 修改文件
- 自動化流程
- 呼叫 API
- 呼叫其他 Agent

## 重點結論

Agent 可以像數位員工一樣協助完成工作。
