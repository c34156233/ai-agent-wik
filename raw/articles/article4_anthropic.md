# Anthropic - Building Effective Agents

來源：
https://www.anthropic.com/research/building-effective-agents

## 摘要

Anthropic 指出 Agent 不一定需要複雜架構。

有效 Agent 通常來自簡單且可組合的設計模式。

## Workflow 與 Agent

### Workflow

固定流程。

例如：

A
↓
B
↓
C

### Agent

動態決策流程。

例如：

Goal
↓
Decision
↓
Tool
↓
Reflection
↓
Next Action

## Agent 設計模式

### Planning

任務規劃。

### Tool Use

工具使用。

### Reflection

自我檢查。

### Evaluation

驗證執行結果。

## 重點結論

Agent 的核心能力不在模型本身，而在於：

- 規劃
- 工具調用
- 驗證
- 修正
