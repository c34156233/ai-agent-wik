# OpenAI - A Practical Guide to Building AI Agents

來源：
https://openai.com/business/guides-and-resources/a-practical-guide-to-building-ai-agents/

## 摘要

OpenAI 將 Agent 定義為能夠代表使用者自主完成任務的系統。

與一般 Chatbot 不同，Agent 不只是產生文字回覆，而是能夠管理整個工作流程。

## Agent 的特徵

- 使用 LLM 進行決策
- 能判斷任務是否完成
- 能自主修正錯誤
- 可以使用外部工具
- 可以與外部系統互動

## 工作流程

User Goal
↓
Planning
↓
Tool Selection
↓
Execution
↓
Validation
↓
Output

## 重點結論

Agent 的核心並不是聊天能力，而是：

1. 自主性（Autonomy）
2. 工具使用（Tool Use）
3. 任務執行（Task Execution）
4. 工作流程管理（Workflow Management）
