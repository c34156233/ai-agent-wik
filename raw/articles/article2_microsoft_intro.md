# Microsoft Learn - Introduction to Agents

來源：
https://learn.microsoft.com/en-us/agents/design-guidelines/intro-to-agents

## 摘要

Microsoft 將 Agent 定義為具有特定知識、能力與工具的 AI 助理。

Agent 透過大型語言模型、知識來源與技能來完成任務。

## Agent 組成

### Instructions

定義 Agent 的規則與目標。

### LLM

理解使用者輸入。

### Orchestrator

決定下一步該做什麼。

### Knowledge

提供資料來源。

例如：

- 文件
- Email
- Meeting
- Database

### Skills

Agent 可以執行的行動。

例如：

- 建立任務
- 發送訊息
- 排程會議
- 產生文件
